# RetouchPi

**RetouchPi (修图派)** is a browser-based photo editor for layered retouching,
selections, compositing, and AI-assisted image work. Open **https://retouchpi.com**
and start editing without installing a desktop application.

> **Open source is coming soon.** This repository currently contains product
> documentation only. RetouchPi's application source code and build artifacts are
> not published here yet.

## What RetouchPi does

- Edit photographs on a layer-based canvas with masks, adjustment layers, blend
  modes, editable text, brushes, gradients, and non-destructive workflows.
- Select, refine, move, and retouch image regions with marquee and lasso tools,
  smart selection, healing, cloning, and content-aware operations.
- Open, edit, and save common image and design formats, including layered PSD
  workflows.
- Generate and edit images with the built-in AI studio.
- Keep ordinary photo editing in the browser; AI-assisted work is the part that
  uses an account and online model service.

See [docs/features.md](docs/features.md) for the fuller feature overview.

## Open-source status

There is no public source release yet. This repository is intentionally limited
to the README and product documentation while the release plan is prepared.

When the source is ready, this repository will add the implementation,
contribution guidance, build instructions, and the applicable open-source
license. Until then, the public repository does not grant access to RetouchPi's
private implementation.

Watch or star this repository to follow the release announcement.
