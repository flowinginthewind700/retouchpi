# RetouchPi feature overview

RetouchPi is a browser-based raster editor for everyday photo work, detailed
retouching, and layered compositions. The hosted product is available now at
**https://retouchpi.com**.

## Editing workspace

- Layer-based documents with visibility, opacity, blend modes, groups, masks,
  clipping, and adjustment layers.
- Non-destructive editing workflows with undo and redo.
- Editable text, vector shapes, paths, gradients, and layer styles.
- Canvas navigation, rotation, zoom, rulers, guides, and grids.

## Selection and retouching

- Rectangular and elliptical marquees, lasso selection, and paint-on masks.
- Magic wand, quick selection, and object selection tools.
- Clone stamp, healing brush, spot healing, patch, red eye removal, and
  content-aware fill or move.
- Crop, transform, liquify, perspective correction, and portrait-focused tools.

## Image adjustment and composition

- Curves, levels, hue and saturation, colour balance, exposure, contrast, and
  other photographic adjustments.
- Filters for blur, sharpening, noise, stylisation, and texture.
- Import, arrange, transform, and composite multiple images in one document.

## Files and output

- Open, edit, and save common raster image formats.
- Layered PSD opening and saving for workflows shared with desktop editors.
- Export flattened images or format-specific output from the browser.

## AI studio

- Text-to-image generation with selectable models and output sizes.
- Image editing from a layer, including source-size-aware handling.
- AI work is metered and requires an account; ordinary photo editing does not.

## Privacy

- Regular editing and document state stay in the browser tab.
- AI-assisted generation and editing are the online workflows that use the
  service and an account.
- The hosted product's current terms and privacy policy are available from the
  editor and the RetouchPi website.

## Project status

RetouchPi is **not open source yet**. This repository is a public documentation
home while the release is prepared. No source code, build artifact, private
design file, or open-source license is published here at this time.

Open source is coming soon. The source release will define the license,
contribution process, and development setup.
